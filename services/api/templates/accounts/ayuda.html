    {% translate "Two things worth knowing" %}

    {% comment %} Las dos reglas del producto que explican **por qué** se comporta como se comporta, y que sin decirlas se leen como fallos: por qué el visor no deja anotar un IFC del disco, y por qué una observación se encuentra siempre aunque el modelo cambie. {% endcomment %}
    {% translate "A finding is anchored to the element, not to a place" %}
    {% blocktranslate %}It is pinned to the IFC element's GUID, which survives a new revision of the model. That is why a finding opened in March is still found in the June model, and why a model opened from your disk cannot take notes: it has no register to file them in.{% endblocktranslate %}
    {% translate "What you can open depends on your role" %}
    {% blocktranslate %}The portal only lists what your role can open, and a client sees only what has been published — not what is still being drafted. If a screen you need is missing, it is a role to ask for, not a button that broke.{% endblocktranslate %}
    {% comment %} Los vocabularios van aquí y no en el rail: son material de lectura, se buscan una vez y desde «cómo se usa». `F11.11` y `F11.12`. {% endcomment %}
    {% translate "BIM vocabulary" %}
    {% blocktranslate %}Sixteen words you will hear on any BIM project — CDE, LOD, IFC, clash detection, 4D, COBie — and, for each one, whether AeroBim does it and where. Half of them it does not: those say what there is instead.{% endblocktranslate %}
    {% translate "Survey vocabulary" %}
    {% blocktranslate %}Point cloud, LiDAR, COPC, DTM and DSM, orthophoto, reference system — the words the flight crew, the surveyor and the modeller each understand differently. With the three warnings that cost a job: ellipsoidal height is not project height, precision is not accuracy, and photogrammetry does not see the ground under the trees.{% endblocktranslate %}
    {% translate "Cost and management vocabulary" %}
    {% blocktranslate %}CAPEX, OPEX, life cycle cost, earned value, KPIs. This is the one that says no the most: AeroBim is not a cost tool, and it is cheaper to read that here than to find out in the meeting where a cost report was promised.{% endblocktranslate %}
    {% comment %} **Las dos preguntas que aparecen en cuanto entra gente real**: «¿esto lleva cookies?» y «¿qué guarda de nosotros?». Las dos tienen respuesta corta y buena, y por eso conviene que esté escrita en una pantalla y no en la cabeza de quien instaló esto. {% endcomment %}
    {% translate "Cookies and your data" %}
    {% blocktranslate %}Two cookies, both needed for it to work, so there is nothing to accept. What AeroBim keeps about you and what it does not do — no analytics, no third parties, and the project files stay on your own server.{% endblocktranslate %}
